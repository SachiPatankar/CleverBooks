# CleverBooks Landing Page

This repository contains the source code for the CleverBooks landing page, a purely frontend project built with React and Vite. It showcases a modern, responsive website with animations.

**Live Demo:** [https://clever-books-green.vercel.app/](https://clever-books-green.vercel.app/)

**Repo:** [https://github.com/SachiPatankar/CleverBooks](https://github.com/SachiPatankar/CleverBooks)

---

## ✨ Features

- **Modern UI:** A clean and modern user interface.  
- **Responsive Design:** Fully responsive layout that works on desktop, tablet, and mobile devices.  
- **Smooth Animations:** Implements framer-motion for engaging user interactions and scroll-based animations.  
- **Dynamic Components:** Uses react-slick for testimonial carousels or image sliders.  
- **Optimized Performance:** Built with Vite for fast development and optimized production builds.  

---

## 🛠️ Tech Stack

This project is built using the following technologies:

- **Framework:** React (v18.2.0)  
- **Build Tool:** Vite  
- **Styling:** Tailwind CSS  
- **Animations:** Framer Motion  
- **UI Components:** React Slick (for carousels)  
- **Utilities:** React Intersection Observer, React Spring

## 🚀 Getting Started

To run this project locally, follow these steps.

### Prerequisites
You must have Node.js (v18 or later) and npm installed on your machine.

### Installation & Setup

```bash
git clone https://github.com/SachiPatankar/CleverBooks.git
cd CleverBooks
npm install
npm run dev
```

The application will be running at http://localhost:5173
 (or the next available port).

## 📜 Available Scripts

**This project uses vite scripts:**

    npm run dev: Starts the development server.
    npm run build: Creates a production-ready build in the dist/ folder.
